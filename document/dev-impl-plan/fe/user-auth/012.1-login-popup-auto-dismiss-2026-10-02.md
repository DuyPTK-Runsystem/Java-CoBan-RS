# Developer Plan: Login Popup Auto Dismiss and Redirect (Plan 012.1)

## 1. Mục tiêu

- Sau khi đăng nhập thành công trên màn hình `LoginView`, popup thông báo thành công sẽ tự động đóng sau 1.5 giây (1500ms) và tự động chuyển hướng (redirect) tới trang phân quyền tương ứng (`successRedirect`).
- Vẫn cho phép người dùng click nút "Đóng" thủ công để đóng ngay lập tức và redirect sớm hơn 1.5s mà không bị trigger 2 lần.
- Đảm bảo dọn dẹp timer (`clearTimeout`) khi popup đóng sớm hoặc khi component unmount (`onUnmounted`) để tránh rò rỉ bộ nhớ hoặc lỗi điều hướng ngầm.
- Giữ nguyên hành vi của popup khi đăng nhập thất bại: không tự đóng sau 1.5s để người dùng có thời gian đọc lỗi và tự bấm đóng.

## 2. Requirement và nguồn tham chiếu

- Phiên bản tài liệu ứng dụng: `v1` (người dùng đã xác nhận).
- Tài liệu liên quan: `document/application-doc/v1/modules/UserModule.md` (mục 3: Login behavior & UI fields).
- Quy trình agent: `.agents/skills/start-agent-session/SKILL.md`, `.agents/skills/frontend-validation/SKILL.md`, `.agents/skills/dev-note/SKILL.md`.

## 3. Phạm vi

### In-scope
- `FE/src/views/auth/LoginView.vue`:
  - Khai báo biến lưu timer `autoDismissTimer`.
  - Trong `handleSubmit`: khi đăng nhập thành công (`popupStatus.value === 'success'`), kích hoạt `setTimeout` 1500ms tự động gọi `closePopup()`.
  - Trong `closePopup`: dọn dẹp `autoDismissTimer` (nếu có) trước khi đóng popup và redirect.
  - Thêm hook `onUnmounted`: dọn dẹp `autoDismissTimer` nếu component bị hủy trước khi timer chạy xong.
- `FE/src/views/auth/LoginView.spec.ts`:
  - Bổ sung/cập nhật test case với fake timers (`vi.useFakeTimers()`):
    + Test popup thành công tự động tắt sau 1500ms và redirect.
    + Test người dùng click "Đóng" thủ công trước 1500ms dọn dẹp timer và redirect ngay lập tức.
    + Test đăng nhập thất bại không tự động đóng sau 1500ms.
- Chạy frontend validation: `npm run test`, `npm run lint`, `npm run build`.
- Tạo Dev Note `document/dev-note/fe/user-auth/012.1-login-popup-auto-dismiss-2026-10-02.md` và cập nhật index tóm tắt.

### Out-of-scope
- Không thay đổi backend API hay logic xác thực/phiên đăng nhập.
- Không thay đổi `LoginForm.vue` hay Storybook stories của form đăng nhập.
- Không đổi hành vi popup của màn hình `RegisterView.vue`.

## 4. Chi tiết triển khai

1. **`LoginView.vue`**:
   - Thêm import `onUnmounted` từ `vue`.
   - Khai báo:
     ```ts
     let autoDismissTimer: ReturnType<typeof setTimeout> | null = null

     function clearDismissTimer(): void {
       if (autoDismissTimer !== null) {
         clearTimeout(autoDismissTimer)
         autoDismissTimer = null
       }
     }
     ```
   - Trong `handleSubmit`:
     ```ts
     clearDismissTimer()
     popupStatus.value = 'success'
     popupMessage.value = 'Đăng nhập thành công.'
     popupVisible.value = true
     autoDismissTimer = setTimeout(() => {
       void closePopup()
     }, 1500)
     ```
   - Trong `closePopup`:
     ```ts
     clearDismissTimer()
     const shouldNavigate = popupStatus.value === 'success'
     popupVisible.value = false
     if (shouldNavigate) {
       await router.replace(successRedirect.value)
     }
     ```
   - Trong `onUnmounted`:
     ```ts
     onUnmounted(() => {
       clearDismissTimer()
     })
     ```
2. **`LoginView.spec.ts`**:
   - Kiểm thử hành vi timer bằng `vi.useFakeTimers()` và `vi.advanceTimersByTime(1500)` hoặc `vi.runAllTimers()`.
   - Đảm bảo dọn dẹp fake timers sau mỗi test case (`vi.useRealTimers()`).
