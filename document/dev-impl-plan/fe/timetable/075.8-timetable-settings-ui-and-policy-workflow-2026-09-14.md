## Mục tiêu và requirement

Khôi phục khả năng sử dụng của minitab **Cấu hình hệ thống** tại `/v2/timetables/settings` cho ADMIN và ACADEMIC_OFFICE theo `BR-V3-TT-004`: layout/popup rõ ràng, policy load đúng, tạo version policy mới để thay đổi mức giảm GVCN, và CRUD diện miễn giảm hiện có.

Policy đang active là bất biến. Theo `BR-V3-TT-002`, thay đổi `4 -> 5` phải tạo policy version mới rồi activate, không cập nhật policy active tại chỗ. API mutation dùng optimistic lock hiện hữu.

## Phạm vi

In-scope:

- sửa `TimetableSettingsView.vue`, `teacherLoadApi.ts`, `types/timetable.ts`, `styles/timetable.css` và test FE liên quan;
- hiển thị trạng thái load/empty/error, policy active, version/source/effective date;
- clone policy vào form tạo version mới; activate kèm `expectedVersion`;
- tạo, sửa và thu hồi eligibility hiện có (`NURSING_CHILD_UNDER_12M`), với validation/date/status/error 409;
- cập nhật Dev Note 75.8 và các summary; chạy quality gates FE cùng browser check read/write scope đã được user yêu cầu.

Out-of-scope:

- không đổi schema, endpoint, DTO hoặc teacher-load evaluator;
- không sửa trực tiếp policy active;
- không thêm `SENIORITY`/miễn giảm thâm niên. Contract v3 hiện chưa có rule code, mức giảm, điều kiện hiệu lực hoặc source cho rule này; FE không được tự phát minh payload/engine.

## Phương án

1. Căn chỉnh CSS settings/dialog theo responsive desktop/mobile, dùng PrimeVue controls và width theo viewport thay vì form cứng 480px/3 cột.
2. Map đúng `ResultPaginationDTO` và policy/eligibility DTO thật; luôn gửi page/size và giữ `expectedVersion` khi activate/update/revoke.
3. Dùng cùng dialog cho create/clone policy; clone chỉ sao chép form state, POST tạo record `DRAFT` mới.
4. Dùng dialog riêng cho create/edit eligibility; edit gọi `PUT` với version và render trạng thái thay vì chỉ có nút thu hồi.

## Validation và rủi ro

Chạy `git diff --check`, `npm run lint`, `npm run test`, `npm run test:coverage`, `npm run build`, `npm run build-storybook`; browser Chrome kiểm tra 3 tab và dialog desktop/mobile. Không claim API/live persistence nếu không có dữ liệu test an toàn. Rủi ro stale update xử lý qua `expectedVersion` và thông báo 409; policy active không bị thay đổi trực tiếp.
