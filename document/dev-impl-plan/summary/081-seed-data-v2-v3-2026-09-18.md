# Plan 081 — Bộ dữ liệu seed v2 và CR v3

## 1. Mục tiêu

Thiết kế bộ dữ liệu demo có thể lặp lại cho baseline v2 và các CR v3 hiện có,
phục vụ development, review UI/API và kiểm thử workflow. Tài liệu này là bản
đặc tả dữ liệu dự kiến; không tự động thay đổi Java, migration hoặc database.

## 2. Nguyên tắc

| Quy tắc      | Áp dụng                                                                           |
| ------------ | --------------------------------------------------------------------------------- |
| Bật seed     | Chỉ chạy khi `APP_SEED_DEMO_ENABLED=true`                                         |
| Idempotency  | Dùng natural key; chạy lại không tạo bản ghi trùng                                |
| Tắt seed     | Không xoá dữ liệu đã tồn tại                                                      |
| Môi trường   | Chỉ dùng dữ liệu demo, email `example.test`, mật khẩu demo                        |
| Trạng thái   | Seed đủ trạng thái workflow cần review, nhưng không giả mạo trạng thái production |
| Contract TBD | Đánh dấu `TBD`, chưa seed cho đến khi contract tương ứng được chốt                |
| Phạm vi      | Không mở rộng ngầm sang module hoặc bảng chưa có contract                         |

## 6. CR v3 — Placement

### 6.2 Placement session

| Session key           | State               | Nội dung                                             |
| --------------------- | ------------------- | ---------------------------------------------------- |
| `PLACE-081-DRAFT`     | `DRAFT`             | Đã chọn năm học, khối, source set, target classes    |
| `PLACE-081-SIM`       | `SIMULATED`         | Có preview, ranking, capacity và missing-data reason |
| `PLACE-081-READY`     | `READY_FOR_CONFIRM` | Không còn blocking conflict                          |
| `PLACE-081-CONFIRMED` | `CONFIRMED`         | Đã tạo enrollment theo idempotency key               |
| `PLACE-081-CANCELLED` | `CANCELLED`         | Có actor, timestamp và reason                        |

## 12. Implementation handoff

Theo yêu cầu mở rộng đã được duyệt, production write-set gồm baseline identity và
academic catalog, placement, notification, functional rooms, scorebook và full
timetable 16 lớp. TKB HK1/HK2 lấy từ toàn bộ bảng design, lần lượt 376/388 tiết
môn học, revision `DRAFT`, `day_of_week=1..5`, audit `SEED_PLAN_081_FULL_V2`.
40 học sinh `STU2600041`–`STU2600080` không được tạo enrollment để phục vụ demo
unassigned; 120 học sinh còn lại vẫn idempotent enrollment. Các scenario lesson log,
score-import session, teacher-load policy và fixture transcript/retake/attendance
mở rộng vẫn là dữ liệu đặc tả, chưa seed. TEST culi chạy validation độc lập.
