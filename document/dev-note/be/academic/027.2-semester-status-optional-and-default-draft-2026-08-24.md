# Dev Note 027.2: Semester Status Optional and Default Draft

## 1. Developer Plan liên quan và approval

- Developer Plan: Implementation Plan được user phê duyệt trực tiếp qua agent ngày `2026-08-24`.
- Related Plan: `document/dev-impl-plan/be/academic/027-academic-subject-teacher-assignment-2026-08-21.md`.
- Phạm vi: Điều chỉnh xử lý `status` trong API Create và Update Semester.

## 2. Phạm vi đã hoàn tất

1. **API Create Semester (`POST /api/v2/semesters`)**:
   - Cho phép `status` nhận giá trị `null` (bỏ `@NotNull` trong `ReqCreateSemesterDTO`).
   - Mặc định gán `SemesterStatus.DRAFT` khi `status == null`.
2. **API Update Semester (`PUT /api/v2/semesters/{id}`)**:
   - Cho phép `status` nhận giá trị `null` (bỏ `@NotNull` trong `ReqUpdateSemesterDTO`).
   - Nếu `status == null`, giữ nguyên trạng thái `status` hiện tại của học kỳ mà không ghi đè.
3. **Unit Tests**:
   - Bổ sung 4 test cases trong `SemesterStatusServiceTest.java`:
     - `createSemesterWithNullStatusDefaultsToDraft`
     - `createSemesterWithExplicitStatusPreservesStatus`
     - `updateSemesterWithNullStatusPreservesExistingStatus`
     - `updateSemesterWithExplicitStatusUpdatesStatus`
