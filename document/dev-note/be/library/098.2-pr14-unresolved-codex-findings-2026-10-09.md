# Dev Note 098.2 — Fix 5 unresolved Codex findings in PR #14

## 1. Scope, baseline và chỉ đạo

- **Ngày thực hiện**: 2026-10-09.
- **Mục tiêu**: Xử lý chính xác 5 findings chưa được giải quyết từ Codex review gần nhất của PR #14 (`e093232ca9`):
  - **Finding #10 (P1)**: Reject future `runDate` in overdue fine batch (`POST /api/v2/library/batch-jobs/overdue-fine`).
  - **Finding #11 (P1)**: Fix `effectiveAt` timezone contract mismatch in circulation policy update (`PUT /api/v2/library/policies/circulation`).
  - **Finding #12 (P2)**: Enforce deterministic FIFO ordering in reservation pagination (`reservedAt ASC, id ASC`) and fix FE queue position index.
  - **Finding #13 (P2)**: Return only currently effective policy in `LibraryPolicyService.current()` (`effectiveAt <= now`), not future-dated policies.
  - **Finding #14 (P2)**: Return timezone-aware circulation timestamps (`OffsetDateTime` with `Asia/Ho_Chi_Minh` offset `+07:00`) across all circulation response DTOs.
- **Ràng buộc đã tuân thủ**:
  - Không sửa lại 9 findings đã giải quyết trước đó.
  - Không tạo git commits, không push, không merge PR, không tự động đóng review threads.
  - User chỉ đạo: Skip `pmdTest` (giữ bắt buộc `pmdMain` và toàn bộ checks static khác).
  - Không thay đổi schema Flyway database hay migration scripts; giữ nguyên kiểu lưu trữ `LocalDateTime` trong database và entities; chỉ chuẩn hóa `OffsetDateTime` tại REST API boundary.
