## Phạm vi đã hoàn thành

- Thêm authenticated `GET /api/v3/notifications/events` và in-memory SSE registry theo user.
- Phát `inbox-changed` sau commit tới các recipient đã resolve; không gửi nội dung notification.
- FE mở authenticated fetch stream, tự reconnect và refresh unread badge/inbox.
- Follow-up badge fix: the SSE callback directly starts unread-count refresh; the custom browser event is only for inbox reload. Unread-count requests bypass HTTP cache; only the latest overlapping request can update the badge, and refresh failures preserve the last known count.
- Cập nhật v3 notification contract, FE API boundary, Developer Plan và Dev Note.
- Không thêm dependency, migration, broker hoặc thay đổi schema.
