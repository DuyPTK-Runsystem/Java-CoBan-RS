## Actual scope

- Allowed `TEACHER` to create drafts, query audience lookup data, access the manage route, publish, and cancel notifications.
- Restricted teacher manage queries to notifications whose `senderId` is the current teacher.
- Added backend ownership checks for teacher publish/cancel/detail actions; `ADMIN` and `ACADEMIC_OFFICE` retain school-wide management.
- Enabled FE teacher access to notification manage/compose routes and manage button.
- Kept detail actions sender-specific by deriving FE management state from the returned `senderId`.
- Added focused authorization, ownership, query-scope, and route regressions.

## Important decisions

- Teacher ownership is enforced in the service layer using the authenticated actor ID; client-supplied IDs are not trusted.
- Existing three-argument service methods remain as compatibility overloads for office-wide callers/tests; controller paths pass the explicit office-scope flag.
- Audience lookup is role-enabled for teachers but remains governed by the existing audience contract; class-assignment-only filtering was not added because it was outside the approved scope.
