# Dev Note 035.1: Academic Office Auto-Configure Calendar on Attendance Session

## Summary

Implemented the approved amendment to Plan 035. The Academic Office/Admin
attendance-session creation flow now ensures the requested calendar day and
period exist as `SCHOOL_DAY`/`SCHEDULED` before creating or returning the
attendance session. The response contract and user-facing behavior are
unchanged, so the user does not need to configure calendar internals first.

Teacher attendance remains strict: it still requires an existing scheduled
calendar session. Existing holidays, non-school days, semester mismatches and
existing `NO_CLASS` periods are protected and are not overwritten. Auto-created
calendar day/session records are written through the existing audit service.
