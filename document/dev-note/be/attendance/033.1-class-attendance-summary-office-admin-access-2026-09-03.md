## 2. Phạm vi đã hoàn thành

- Mở quyền `GET /api/v2/attendance/classes/{classId}/summary` cho `ADMIN` và `ACADEMIC_OFFICE`.
- `ADMIN` và `ACADEMIC_OFFICE` được đọc summary mọi lớp mà không cần hồ sơ giáo viên hoặc phân công GVCN.
- `TEACHER` vẫn phải là GVCN của lớp trong khoảng `from` đến `to`.
- `STUDENT` vẫn nhận `403`; anonymous vẫn nhận `401`.
- Không thay đổi aggregation, pagination, query/response DTO, quy tắc suy diễn `PRESENT`, database schema,
  session mutation hoặc student history.

## 4. Quyết định triển khai

- Phân quyền coarse-grained ở controller bằng `hasAnyRole`; ownership theo use case vẫn nằm trong `AttendanceGuard`.
- Dùng method guard mới thay vì nới lỏng `validateCurrentUserHomeroomInRange`, để không ảnh hưởng các API mutation
  attendance đang yêu cầu GVCN.
- Integration test dùng class id không tồn tại để chứng minh office/admin đã qua authorization và được xử lý tiếp
  ở domain layer với `404`, thay vì bị chặn sớm bằng `403`.
