# Dev Note 076.14 FE — Notification unread awareness after login

## 1. Plan and approval

- Related Developer Plan: `document/dev-impl-plan/fe/notification/076.14-unread-login-awareness-2026-09-21.md`
- Application-document version: v3.
- Approval: user explicitly delegated implementation to separate dev and QA workers.

## 2. Actual scope completed

- Added a typed `fetchUnreadNotificationCount` helper using the existing v3 inbox endpoint
  with `unreadOnly=true`, `page=0`, and `size=1`; the count comes from backend
  `meta.totalItems`.
- Authenticated shell loads the count on mount/activation and displays it as a badge on
  `Thông báo`; zero and failed count requests hide the badge without blocking the workspace.
- Successful mark-read dispatches a local event so the shell refreshes the badge.
- No backend endpoint, push, polling, email fallback, or v2 semester notification change.
