# Dev Note 076.7 FE — Notification audienceDetails contract

## Developer Plan và approval

- Related plan: `document/dev-impl-plan/fe/notification/076-targeted-notification-ui-2026-09-15.md`.
- Application-document version: `v3`.
- Approval: user explicitly requested FE-only integration of the current BE `audienceDetails` contract.

## Actual scope

- Added the display-safe `NotificationAudienceDetails` type and optional `audienceDetails` field to `NotificationItem`.
- Updated `NotificationDetail.vue` to render `displayLabel`, `recipientCount` and `recipientDisplayNames` from `audienceDetails`.
- Removed detail rendering based on `targetReference`; no raw user/class identifiers are used as a display fallback.
- Added Vietnamese fallback copy when audience metadata is absent or incomplete.
- No backend, request payload, or test files were changed for this task.

## Files changed

- `FE/src/types/notification.ts`
- `FE/src/components/notification/NotificationDetail.vue`

## Contract mapping

| BE field | FE usage |
| --- | --- |
| `audienceDetails.displayLabel` | Nhãn đối tượng nhận; fallback theo `audienceType` nếu thiếu |
| `audienceDetails.recipientCount` | Số người nhận, formatted theo `vi-VN` |
| `audienceDetails.recipientDisplayNames` | Danh sách tên người nhận, lọc giá trị rỗng |
| `audienceDetails.displayDataAvailable` | Hiển thị cảnh báo tiếng Việt khi metadata chưa đầy đủ |
| `audienceDetails.audienceType` | Fallback label khi `displayLabel` thiếu |
