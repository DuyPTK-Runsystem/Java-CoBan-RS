- Related plan: `document/dev-impl-plan/be/notification/076.3-notification-ux-audience-lookup-2026-09-17.md`

## 2. Scope đã hoàn tất

- Thêm typed FE services cho lookup lớp và người nhận cá nhân, có `q`, zero-based `page`, `size`.
- Thay nhập tay class ID bằng tìm kiếm và dropdown lớp.
- Thay nhập chuỗi User ID bằng tìm kiếm bất đồng bộ, chọn nhiều người, chip và bỏ chọn.
- Tạo payload canonical: `CLASS` chỉ gửi `targetReference`; `INDIVIDUAL` chỉ gửi `recipientUserIds`; không gửi comma string hoặc cả hai.
- Giữ nguyên lựa chọn trên lỗi create `400/422/409` bằng cách không reset state trong view.

## 3. File đã thay đổi

- `FE/src/types/notification.ts`: thêm DTO lookup và query type.
- `FE/src/services/notificationApi.ts`: thêm hai hàm lookup typed cho endpoint v3.
- `FE/src/components/notification/NotificationAudienceSelector.vue`: picker lớp, async individual search, multi-select, chips, loading/empty/error và pagination.
- `FE/src/components/notification/NotificationComposer.vue`: state `recipientUserIds`, validation và canonical request.
- `FE/src/views/notification/NotificationComposerView.vue`: thông báo lỗi thân thiện cho `400/422/409`, không xóa lựa chọn.
- `FE/src/components/notification/NotificationAudienceSelector.spec.ts`: cập nhật kỳ vọng picker/multi-select và mock lookup/auth/router để lifecycle async deterministic.
- `FE/src/components/notification/NotificationAudienceSelector.stories.ts`: chuyển fixture cá nhân sang `recipientUserIds` và class reference canonical.

## 4. Contract assumptions

- Endpoint lớp: `GET /api/v3/notifications/audiences/classes`.
- Endpoint người nhận: `GET /api/v3/notifications/audiences/individuals`.
- Response là `ResultPaginationDTO` với `meta.page`, `meta.pageSize`, `meta.totalPages`, `meta.totalItems` và `result`.
- Class DTO có `classId`, `classCode`, `className`, `academicYearId`, `eligibleRecipientCount`.
- Individual DTO có `userId`, `displayName`, optional `studentCode`, `username`.
- BE là nguồn quyết định cuối cùng về existence, eligibility, snapshot và idempotency.
