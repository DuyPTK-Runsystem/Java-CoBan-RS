## 2. Scope đã hoàn tất

- CLASS dùng một class picker/combobox duy nhất với filter nội tại; không còn input hoặc search field yêu cầu class ID. `classId` chỉ được giữ trong state và canonical `targetReference` payload.
- INDIVIDUAL có tìm kiếm tên/mã/tài khoản, role filter, student-class filter, teacher-class filter, clear filters, server-side pagination, checkbox multi-select và chips.
- Selection được giữ khi đổi filter/trang; filter metadata không đi vào composer payload.
- Bổ sung loading, empty, error/retry và responsive layout cho selector.
- Mở rộng typed notification lookup query/response để nhận role và class context do BE contract có thể trả về.

## 3. File đã thay đổi

- `FE/src/types/notification.ts`: thêm role/class context và `roleCode`, `studentClassId`, `teacherClassId` vào lookup query.
- `FE/src/services/notificationApi.ts`: serialize các query filter đúng tên backend và bỏ qua filter chưa chọn.
- `FE/src/components/notification/NotificationAudienceSelector.vue`: thiết kế lại class picker và individual selector 076.4.
- `FE/src/components/notification/NotificationAudienceSelector.spec.ts`: cập nhật kỳ vọng class picker và coverage cho filter/empty state; bổ sung Checkbox stub để test harness không khởi tạo PrimeVue Checkbox thật.
- `FE/src/components/notification/NotificationAudienceSelector.stories.ts`: thêm story individual có selection/filter context.
- `FE/src/services/notificationApi.spec.ts`: thêm coverage query serialization cho lookup individual.

## 4. Quyết định implementation

- Dùng class lookup hiện có làm option cho cả student-class và teacher-class filter; FE không tự suy diễn danh sách lớp hoặc eligibility.
- `NotificationComposer` tiếp tục chỉ emit `targetReference` cho CLASS hoặc `recipientUserIds` cho INDIVIDUAL; không nhận filter metadata.
- Optional response fields (`roleCodes`, `studentClass`, `teacherClasses`) được render khi BE trả về và không làm FE tự tạo dữ liệu thiếu.
- Test harness của selector stub `Checkbox` cục bộ; UX và component production không thay đổi.
