## Actual scope

  - manager view: `Theo dõi lượt đọc` and `Chưa có thống kê tổng hợp` when the API has no aggregate read data.
- Added an explanatory hint for the manager view instead of displaying an ambiguous dash.
- Added audience context without exposing internal identifiers: class references render as `Đã chọn lớp học`, while individual references render as a recipient count; names remain omitted because the API response does not provide display metadata.
- Refined notification management header spacing, button spacing, separator, copy, and narrow-screen layout.
- Kept the backend/API contract unchanged.
