## Phạm vi thực tế đã triển khai

- Đưa button `Mở buổi điểm danh` xuống sau toàn bộ context fields: năm học,
  học kỳ, lớp, ngày điểm danh và buổi.
- Cân chỉnh action thành cột riêng rộng `190–210px` trên desktop, full width
  ở layout hẹp và mobile; các context control chuyển sang 3 cột ở tablet.
- Tách trạng thái loading của button khỏi calendar preflight và các mutation
  ngoại lệ; button chỉ phản ánh `sessionOpening` của request mở session.
- Cập nhật Storybook để hiển thị button mặc định và có state riêng khi đang mở
  session.

## Quyết định triển khai

- Giữ nguyên public event `open` và API contract hiện tại.
- Với role `ADMIN` hoặc `ACADEMIC_OFFICE`, button gọi `POST` create-or-get
  session qua `attendanceApi`; response được dùng để tải roster học sinh.
- Teacher không thấy button; teacher vẫn tự động đọc session đã tồn tại bằng
  `GET` theo flow của Plan 056.1.
- Không thay đổi backend, endpoint, enum, business rule hoặc legacy UI.
