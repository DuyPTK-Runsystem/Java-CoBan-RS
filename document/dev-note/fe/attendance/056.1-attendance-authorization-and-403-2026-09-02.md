## Đã triển khai

### Amendment: automatic existing-session lookup

- BE bổ sung `GET` read-only trên teacher và academic-office attendance-session
  base với query `classId`, `semesterId`, `attendanceDate`, `sessionPeriod`;
  trả `404` khi session chưa tồn tại và không tạo dữ liệu.
- FE thay flow phụ thuộc nút `Mở buổi điểm danh` bằng tự động gọi `GET` khi đủ
  context; sau khi nhận session hợp lệ thì tự tải roster.
- `AttendanceContextPanel` đã bỏ button/event mở session; `POST` create-or-get
  vẫn giữ nguyên cho các client cần tạo session.

### Amendment: role-based Attendance workspace navigation

- Khôi phục button `Mở buổi điểm danh` chỉ cho `ADMIN` và
  `ACADEMIC_OFFICE`; button gọi `POST` create-or-get.
- `STUDENT` chỉ thấy mini-tab `Lịch sử của học sinh`, mặc định mở tab này;
  session và báo cáo lớp bị ẩn.
- `TEACHER`, `ADMIN` và `ACADEMIC_OFFICE` thấy mini-tab `Báo cáo lớp`.
  Theo approval hiện tại, không thêm BE filtering lớp theo assignment teacher.
- Xóa button `Tải báo cáo` và event search thủ công; summary tự tải khi đủ
  lớp, học kỳ, từ ngày và đến ngày.

## Amendment risks and limitations

- GET does not create a session. A missing session returns `404`, so the UI
  remains empty until another approved flow creates it through `POST`.
- `cd FE && npm.cmd run test` | **PASS** - 45 files, 142 tests |
- `cd FE && npm.cmd run test:coverage` | **PASS** - 85.52% statements, 70.98% branches |
- `cd FE && npm.cmd run build-storybook` | **PASS** |
- Full browser walkthrough was not run because no live browser session/backend walkthrough was available.

- BE thêm `RestAccessDeniedHandler`, trả envelope `403 Forbidden` cho authenticated request thiếu quyền; `401` vẫn do authentication entry point xử lý.
- BE chuyển quyền `GET /api/v2/academic-years` và `GET /api/v2/classes` sang method-level, cho phép `TEACHER`; các mutation vẫn chỉ `ADMIN`/`ACADEMIC_OFFICE`.
- Auth/account response trả `roles`; FE lưu và validate role summary.
- Attendance workspace chọn `teacher` hoặc `office` session API theo role `TEACHER`/`ACADEMIC_OFFICE`/`ADMIN`; không logout khi 403.
- Bổ sung test FE cho office scope và BE security matrix cho teacher context read.
- Bổ sung developer trace xuyên suốt calendar validation để phân biệt thiếu
  `calendar_day`, sai scope/ngày, và không có session `SCHEDULED`.
- Bổ sung nhánh trace riêng cho `calendar_day` không tồn tại và `semesterId`
  không khớp; đây là nguyên nhân được khoanh từ log request `a9d1e932-24db-490a-a241-e4a71d0fa6a0`.
