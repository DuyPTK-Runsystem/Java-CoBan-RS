## Quyết định triển khai

- `PUT` is a guarded full replacement. A tuple cannot change after it has been
  used by `class_subject`; status-only update remains available for that case.
- `DELETE` changes status to `INACTIVE`, never physically deletes the row or
  existing class-subject offerings, and is idempotent for an already inactive
  record.
- GET uses one filtered repository query and returns both active and inactive
  records when no status filter is supplied.
- No database migration was added because the existing V5 schema already has
  the required table, constraints and indexes.
- Validation was split into `SubjectApplicabilityValidator` and list methods
  were consolidated after PMD identified service/repository size violations.
  This preserves behavior without changing PMD or Checkstyle configuration.
- The existing user change in
  `BE/BaiTap-RS/src/main/resources/application.properties` was preserved and
  is unrelated to this task.
