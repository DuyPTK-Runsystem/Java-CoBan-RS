# Application Documentation v2

This folder is the source of truth for the modular application baseline.

## Scope

- `ApplicationContext.md`: modular project context.
- `RequirementBaseline.md`: v2 requirement baseline.
- `ContractMigrationScopeFreeze.md`: contract and migration freeze.
- `modules/`: modular feature contracts and business rules.
- `data-model/`: persistence model, constraints, calculations and migrations.
- `change-request/`: v2 change requests and their decisions.

Read `RequirementBaseline.md` first, then select only the modules and data-model
documents relevant to the task. Do not use v1 documents to fill gaps in v2.
