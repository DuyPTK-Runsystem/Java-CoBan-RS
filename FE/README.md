# Academic Core Frontend

Vue 3 + Vite + TypeScript skeleton for the Academic Core student-management screens.

## Commands

```bash
npm install
npm run dev
npm run lint
npm run build
npm run storybook
npm run build-storybook
```

Copy `.env.example` to `.env` when a public API base URL is available. REST integration, authentication state and persistence are intentionally deferred to later approved plans.
